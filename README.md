# Aegis Android releases

This repository distributes signed universal Aegis Android APKs and public release notes only. The application source, study curriculum and question database are private and are not hosted here.

Use this repository URL in Obtainium:

https://github.com/RavensightLLC/Aegis-Releases

Download the universal APK from Releases. Android handles installation approval. On first launch, import your separately provided private curriculum package. Existing local curriculum and progress are retained when you install later versions over the existing app.
